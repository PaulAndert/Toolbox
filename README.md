# Python Tools Web App (Django)

This project is a student project for the module *Object Oriented Scripting Languages* at [TH Brandenburg](https://www.th-brandenburg.de/startseite/) in the Summer Semester 2022.
  
This project is a **web-based platform** implemented in **Python Django**, providing a collection of default tools and a **dynamic framework for adding new tools**.  

- RGB Converter  
- Binary Calculator  
- Hexadecimal Calculator  
- Timer / Countdown  
- Standard Calculator  
- Radio Stream Downloader

## Requirements
- Python
- Django

## Installation
```console
git clone https://github.com/PaulAndert/Toolbox.git
cd Toolbox
python manage.py migrate
python manage.py runserver
```
